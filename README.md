## 📌 Proyecto destacado

### 🔎 CommitTrace

> Plataforma para visualizar y analizar métricas de actividad y contribución en equipos de desarrollo mediante integración con GitHub.

<p>
  <img src="https://img.shields.io/badge/Java-F0C808?style=flat-square&logo=openjdk&logoColor=000000"/>
  <img src="https://img.shields.io/badge/Spring_Boot-F0C808?style=flat-square&logo=springboot&logoColor=000000"/>
  <img src="https://img.shields.io/badge/Spring_Security-F0C808?style=flat-square&logo=springsecurity&logoColor=000000"/>
  <img src="https://img.shields.io/badge/JPA-F0C808?style=flat-square&logoColor=000000"/>
  <img src="https://img.shields.io/badge/PostgreSQL-F0C808?style=flat-square&logo=postgresql&logoColor=000000"/>
  <img src="https://img.shields.io/badge/Angular-F0C808?style=flat-square&logo=angular&logoColor=000000"/>
  <img src="https://img.shields.io/badge/React-F0C808?style=flat-square&logo=react&logoColor=000000"/>

  <img src="https://img.shields.io/badge/Docker-F0C808?style=flat-square&logo=docker&logoColor=000000"/>
</p>

El proyecto busca centralizar información proveniente de repositorios de GitHub y transformarla en información visual que facilite el análisis de contribuciones y actividad de los equipos.

- 📁 Visualización de repositorios
- 🌿 Análisis de ramas
- 💻 Métricas de commits
- 🔀 Seguimiento de Pull Requests
- 🚀 Información de releases
- 👥 Equipos y miembros
- 📊 Visualización de métricas
- 🔐 Autenticación y autorización
- 🔄 Integración con GitHub API
- 📅 Consulta de información histórica
