## 📌 Proyecto destacado

### 🔎 CommitTrace

> Plataforma para visualizar y analizar métricas de actividad y contribución en equipos de desarrollo mediante integración con GitHub.

**Stack principal**

`Java` `Spring Boot` `Spring Security` `JPA` `PostgreSQL` `Angular` `React` `GitHub API` `Docker`

El proyecto busca centralizar información proveniente de repositorios de GitHub y transformarla en información visual que facilite el análisis de contribuciones y actividad de los equipos.

### Algunas funcionalidades

- 📁 Visualización de repositorios
- 🌿 Análisis de ramas
- 💻 Métricas de commits
- 🔀 Seguimiento de Pull Requests
- 🚀 Información de releases
- 👥 Información de equipos y miembros
- 📊 Visualización de métricas
- 🔐 Autenticación y autorización
- 🔄 Integración con GitHub API
- 📅 Consulta de información histórica
